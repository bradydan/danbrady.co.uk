# danbrady.co.uk

Documentary photography portfolio for Dan Brady.

- `index.html` — the site (home, projects index, project pages, photo viewer, about, contact)
- `nocturne.css` — design tokens and base styles
- `image-slot.js` — image placeholder component
- `support.js` — runtime

Sample photographs are placeholders served from picsum.photos; replace the `src` values with real files.

## Local setup

```sh
cd ~/Documents/GitHub/danbrady.co.uk
git init
git add .
git commit -m "Initial layout"
git branch -M main
git remote add origin git@github.com:bradydan/danbrady.co.uk.git
git push -u origin main
```
